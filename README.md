# JobFlow — практики 01–05

Небольшая учебная программа-планировщик дел на Go. Исходно создана как список дел на день; последовательно расширена расчётом времени, приоритетами, напоминаниями, функциями, срезами и `map`.

## Возможности текущей версии (практика 05)

- Показывает три дела и их длительности.
- Считает время работы и **два перерыва**, показывает часы и минуты, сравнивает план с доступным временем.
- Проверяет непустое название, приоритет 1–3 и число напоминаний 0–3.
- Не выводит напоминания для завершённого дела и недопустимого ввода; приоритет 2–3 считается срочным.
- Выбирает дела по порядку из среза длительностей в рамках бюджета; пустой список допустим, отрицательные длительности отклоняются.
- Хранит записи `ID → название` в `map[string]string`; выполняет `create`, `get`, `update`, `remove` и показывает состояние с сортировкой ID.

## Структура проекта

- `main.go` — основной сценарий, расчёт и обработка выбранного дела.
- `plan.go` — функции `describe`, `validPriority`, `isUrgent`, `totalMinutes`, `printReminders`.
- `collections.go` — алгоритм выбора дел по бюджету.
- `storage.go` — операции CRUD, сортировка ID, демонстрационная история.
- `plan_test.go`, `storage_test.go` — автоматические тесты Go.
- `NOTES.md` — требования, расчёты, проверочные сценарии, ограничения и история практик 01–05.
- `go.mod` — модуль `jobflow`.

## Как запустить

Открыть терминал в папке `JobFlow` (там, где лежит `go.mod`) и выполнить по одной команде:

```powershell
go fmt ./...
go run .
go test ./...
```

Важно: после разделения функций на несколько файлов запускать `go run .`, а не `go run main.go`.
