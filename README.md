# JobFlow — практика 05

Назначение: личный план дел и тренировка Go.

Срезы, бюджет, map, CRUD, сортировка ID и воспроизводимая история.

## Как запустить

Открыть терминал **в папке JobFlow**, содержащей `go.mod`, затем:

```powershell
go fmt ./...
go run .
go test ./...
```

Важно: после появления `plan.go` запускать `go run .`, а не `go run main.go`.
